# TechStore Online

Proyecto final de Patrones de Software desarrollado para la tienda online TechStore.

## Descripción

Este repositorio contiene el análisis, los diagramas y la implementación inicial de un sistema de ventas para una tienda de productos tecnológicos. El proyecto está organizado en versiones que muestran la evolución del diseño y la aplicación de patrones de software.

## Estructura del repositorio

- `docs/`: documentación del proyecto.
  - `01_ficha_cliente.md`: ficha del cliente y requisitos.
  - `02_antipatrones.md`: análisis de antipatrones detectados.
  - `03_justificacion_patrones.md`: justificación de los patrones utilizados.
- `uml/`: diagramas UML del sistema.
- `v0/`: versión inicial del sistema.
- `v1/`: versión mejorada con lógica de venta y salida esperada.

## Requisitos

- Compilador de C++ compatible con C++17.
- Git para clonar y versionar el repositorio.

## Compilación

```bash
g++ v1/main.cpp -o techstore
./techstore
```

## Objetivo del proyecto

Demostrar cómo el uso correcto de patrones de diseño mejora la mantenibilidad, la extensibilidad y la claridad del código en un sistema de e-commerce.
